# BUY BUTTON · آخرین خریدار

یک بازی وب پیکسلی داستانی، با فارسی پیش‌فرض و هشت زبان. نسخهٔ 0.3.0 یک میدان آزاد، هشت فصل و موسیقی قابل‌نواختن دارد؛ برای رسیدن به محصول نهایی به آزمون بازیکن، تنظیم ریتم و بازبینی انسانی ترجمه‌ها نیاز دارد.

## اجرای محلی

Node.js نسخهٔ ۲۰ یا جدیدتر:

```powershell
npm run dev
```

سپس نشانی `http://localhost:4173` را در مرورگر باز کنید. اجرای خود بازی وابستگی تولیدی و نصب پکیج نمی‌خواهد. برای استفاده از پورت دیگر، متغیر `PORT` را تنظیم کنید.

```powershell
npm run check
npm test
npm run build
```

خروجی `dist` یک سایت ایستا است و می‌تواند روی هاست ایستا قرار گیرد. برای پیش‌نمایش خروجی: `node server.mjs --dist`. بازکردن مستقیم فایل با `file://` به دلیل ماژول‌های جاوااسکریپت پشتیبانی نمی‌شود؛ از سرور محلی استفاده کنید. سرور توسعه برای انتشار عمومی طراحی نشده است.

## امکانات پیاده‌شده

- میدان باز ۱۹۲۰×۱۲۸۰ با خیابان‌های حلقه‌ای، هفت مسیر آزاد و یک بازار پایانی. ورود و خروج از فصل‌های نیمه‌تمام آزاد است.
- هشت فصل، ۲۴ ایستگاه با ۴۸ مرحله، هشت صحنهٔ اختصاصی، ۳۲ سند، تا ۱۵ تصمیم ثبت‌شده و هشت پایان.
- شش کشف اختیاری و سه پروژه: تعمیر چراغ‌ها، کامل‌کردن کارت‌پستال‌ها و معمای سنگ‌های آوا؛ محیط تغییر می‌کند و یک گربه همراه سفر می‌شود.
- رادیوی فردا: نه تم اصلی با تنظیم ۶۴ میزانی، انتخاب آزاد قطعه، میکسر پنج لایه، صدای محیط جدا و ساز چهارردیفیِ شانزده‌مرحله‌ای با ذخیرهٔ ریتم.
- پنج خانوادهٔ معما: مدار چرخشی، حافظهٔ سیگنال، تطبیق دو دفتر، چراغ‌ها و رمز. همه از بذر ثابت ساخته می‌شوند و قابل‌حل‌اند.
- حرکت با WASD یا کلید جهت، دویدن با Shift، تعامل با E، نور رسید با Space، دفترچه با J، فصل‌ها با M و توقف با Escape و حرکت خمیده با C. دکمهٔ ⌂ بازگشت آزاد به میدان، ⛶ گسترش صحنه و ☷ نمایش هدف‌هاست.
- حرکت به مقصد با کلیک/لمس و دکمه‌های لمسی. مسیر‌یابی مانع‌ها را در نظر می‌گیرد.
- سایه با دید محدود به دیوارها، شنیدن دویدن، جست‌وجو و عقب‌نشینی از نور؛ پناه‌های قابل‌استفاده با C. تعلیق تدریجی، پوشش پیکسلی چهره‌ها، شدت ملایم/سینمایی و حالت آرام. برخورد پیشرفت را پاک نمی‌کند.
- راهنمای معما و حل کمکی اختیاری؛ استفاده از کمک، سرعت بازی و نوع کنترل وارد بازتاب انتخاب‌ها نمی‌شوند.
- ذخیرهٔ خودکار محلی، ذخیرهٔ بین مراحل معما، خروجی JSON و بازیابی فایل با اعتبارسنجی. مراحل تکمیل‌شده پس از بارگذاری حفظ می‌شوند؛ حرکات جزئیِ مرحلهٔ ناتمام پس از بستن آن مرحله از ابتدا آغاز می‌شود.
- تغییر زبان درجا: فارسی، چینی ساده‌شده، انگلیسی، عربی، اسپانیایی، هندی، فرانسوی و پرتغالی. متن داستان اجرایی، راهنماها، انتخاب‌ها و پایان‌ها ترجمه شده‌اند. نام منابع و شناسه‌های آرشیوی ممکن است به زبان اصلی باقی بمانند.
- قلم فارسی محلی، RTL، اندازهٔ متن، کاهش حرکت، صدای اختیاری، تلهٔ فوکوس پنجره‌ها و توقف آزاد.
- دفترچهٔ منابع با مرز روشن سند تاریخی و بازسازی خیالی. نتیجهٔ پایانی توصیف تصمیم‌های بازی است، نه آزمون شخصیت.

## زمان تجربه

هدف طراحی یک بار بازی حدود ۵۵ تا ۷۵ دقیقه است. این عدد هنوز با مطالعهٔ بازیکنان اندازه‌گیری نشده و تضمین مدت نیست. ۴۸ مرحله، هشت صحنهٔ متنوع، خواندن و اکتشاف برای این هدف طراحی شده‌اند؛ مسیر آزاد می‌تواند بخشی از فصل‌ها را کنار بگذارد و مدت کوتاه‌تر شود. هیچ شمارش معکوس یا انتظار اجباری برای طولانی‌کردن بازی وجود ندارد. حل کمکی و ردکردن خواندن می‌توانند زمان را بسیار کوتاه کنند. دشواری بعضی معماهای چراغ ممکن است برای بعضی افراد زمان بیشتری بخواهد.

برای تنظیم نهایی: حداقل پنج بازیکنِ ناآشنا، با سنجش جداگانهٔ زمان اکتشاف، خواندن، معما، تعداد درخواست کمک و نقاط خروج. اطلاعات فقط با رضایت جمع‌آوری شود. سپس مراحل تکراری کوتاه یا با تعامل داستانی تازه جایگزین شوند.

## ساختار و بهینه‌سازی

- `src/engine.js`: شبیه‌سازی با گام ثابت ۶۰ هرتز، ورودی، دوربین و سایه. سرعت بازی از نرخ نمایش مستقل است.
- `src/art.js`: تصویر پیکسلی اصلی، شخصیت‌ها و محیط؛ پس‌زمینهٔ ثابت هر اتاق یک بار پیش‌رندر می‌شود.
- `src/puzzles.js`: منطق خالص و مستقل معماها؛ بدون وابستگی به DOM.
- `src/puzzle-ui.js`: نمایش و کنترل معماها.
- `src/state.js`: ذخیره، اعتبارسنجی ورودی، پایان‌ها و مسیر‌یابی.
- `src/content.js`: هشت فصل، اسناد، انتخاب‌ها، پایان‌ها و تعریف محیط.
- `src/i18n.js`: هشت زبان، جهت نوشتار و جایگذاری متغیرها.
- `src/main.js`: رابط، دفترچه، تنظیمات، ذخیره و اتصال سیستم‌ها.
- `src/open-world.js` و `world-art.js`: میدان، سفر غیرخطی، کشف‌ها، پروژه‌ها و تصویر محیط باز.
- `src/episodes.js` و `episode-logic.js`: متن و منطق هشت صحنهٔ اختصاصی.
- `src/horror.js`: دید سایه، مسیر‌یابی و رویدادهای تدریجی.
- `src/audio.js`: زمان‌بندی موسیقی با ساعت صوتی و افکت‌ها.
- `src/music-score.js`: نه تم، ملودی‌ها، آکوردها، ریتم‌ها و تنظیم هشت‌بخشی.
- `src/audio-synth.js`: سازهای ساخته‌شده با Web Audio، صدای استریو، بازتاب، تأخیر و کنترل دامنه.
- `src/music-ui.js`: رادیو، میکسر و ساز تعاملی؛ بدون فایل صوتی بزرگ در خروجی بازی.

Canvas داخلی ۶۴۰×۳۶۰ است. سه حالت کیفیت وجود دارد: بالا، سبک و تطبیقی. حالت سبک جلوه‌های تزئینی را کم می‌کند و نمایش را به حدود ۳۰ فریم هدف می‌برد؛ شبیه‌سازی مستقل می‌ماند. در حالت تطبیقی، زمان فریم‌ها مبنای انتخاب است. DOM هدف‌ها فقط پس از تغییر داده بازسازی می‌شود. شبیه‌سازی و صدا هنگام پنهان‌شدن صفحه متوقف می‌شوند؛ هنگام پنجره‌های متنی، صحنهٔ ثابت بی‌دلیل دوباره رسم نمی‌شود.

حجم خام و برآورد فشرده در `artifacts/build-report.json` تولید می‌شود. این برآورد جای پروفایل روی تلفن واقعی را نمی‌گیرد. برای بهینه‌سازی بعدی، ابتدا گزارش دستگاه هدف و زمان فریم ثبت شود؛ سپس بودجهٔ جلوه‌ها یا اندازهٔ Canvas تغییر کند.

## داده و محتوا

ساختار ذخیره اکنون نسخهٔ ۳ است. ذخیره‌های نسخه‌های ۱ و ۲ هنگام خواندن مهاجرت می‌کنند؛ تصمیم جدیدی به گذشته نسبت داده نمی‌شود. کلیدهای محلی: `last-buyer.save.v1` و `last-buyer.settings.v1`. داده‌ای برای تحلیل یا تبلیغات ارسال نمی‌شود. هیچ کیف پول، پرداخت یا سفارش واقعی وجود ندارد. پاک‌کردن داده‌های سایت، ذخیره را پاک می‌کند؛ پیش از آن از خروجی ذخیره استفاده کنید.

داستان کامل: [story.fa.md](story.fa.md). پژوهش: [research.fa.md](research.fa.md). طرح روایی پیش از اجرا: [game-design.fa.md](game-design.fa.md). طراحی اجراشدهٔ شهر، صحنه‌ها و موسیقی نسخهٔ ۰٫۳: [director-edition.fa.md](director-edition.fa.md).

فونت Vazirmatn از نسخهٔ v33.003 با مجوز SIL Open Font License استفاده شده؛ متن مجوز در `assets/OFL.txt` است. تصویرها، صداها و شخصیت‌ها برای همین پروژه با کد ساخته شده‌اند.

## اجرای آزمون مرورگر

این مرحله اختیاری و مربوط به توسعه است. `playwright-core` فقط وابستگی آزمون است و به خروجی بازی وارد نمی‌شود:

```powershell
npm ci
npm run dev
# در ترمینال دوم، با Microsoft Edge نصب‌شده:
npm run test:browser
```

آزمون‌ها در مرورگر جداگانه و با داده‌های ساختگی محلی اجرا می‌شوند. پرونده‌های مرورگر شخصی را باز نمی‌کنند. ابزار `browser-journey.mjs` موقعیت اولیهٔ شخصیت را برای هر مورد آزمون آماده می‌کند و سپس همهٔ مراحل معما، صحنه‌ها، انتخاب‌ها و پایان‌ها را با ورودی واقعی رابط اجرا می‌کند؛ آزمون مدت تجربهٔ انسان نیست. خروجی‌ها و تصویرها در پوشهٔ `artifacts` قرار می‌گیرند.

## حدود این نسخه

این نسخه مسیر کامل قابل‌بازی دارد؛ کیفیت نهایی یک اثر تجاری با یک مرحلهٔ ساخت تضمین نمی‌شود. تنظیم دقیق مدت یک ساعت، تنظیم موسیقی با شنیدن انسانی، بازبینی بومی ترجمه‌ها، تست Safari/Firefox و سنجش روی موبایل واقعی کارهای انتشار نهایی‌اند. وضعیت آزمون‌های انجام‌شده در `QA.md` ثبت می‌شود.

## سفر آزاد و موسیقی

برای بازشدن بازار آخر، مغازه (فصل ۱)، اتاق تسویه (فصل ۷) و دو فصل دلخواه دیگر باید با صحنه و تصمیمشان کامل شوند. بقیهٔ مسیرها از ابتدا بازند؛ نقشه امکان سفر مستقیم و علامت‌گذاری مقصد دارد. برای دیدن همهٔ موقعیت‌ها، هر هشت فصل را کامل کنید. پایان شاهد به مدارک بیشتر و رضایت مشخص نیاز دارد؛ پایان صبح قرضی به انتخاب تماس اول وابسته است.

روی «رادیوی فردا» در منو یا نام قطعه در گوشهٔ صحنه بزنید. میکسرِ پنج لایه، بلندی موسیقی و محیط، سرعت ۶۰ تا ۱۳۲ BPM و چهار ردیفِ شانزده‌مرحله‌ای در دسترس‌اند. ذخیرهٔ ریتم در تنظیمات محلی است و حتی بازی تازه آن را پاک نمی‌کند. تنظیم سفارشی اختیاری است؛ خاموش‌کردنش تنظیم اصلی قطعه را بازمی‌گرداند. حالت «موسیقی همراه سفر» انتخاب قطعه را به مکان وصل می‌کند. موسیقی در صفحهٔ پنهان متوقف می‌شود. موسیقی و افکت‌ها تألیف همین پروژه‌اند؛ هیچ صدای تجاری نمونه‌برداری نشده است.

هر قطعه چرخهٔ ۶۴ میزان دارد و سپس تکرار می‌شود. نه ملودی و تنظیم وجود دارد؛ ادعای ساعت‌ها موسیقیِ بدون تکرار یا میکس نهاییِ استودیویی نداریم. فایل شنیدنیِ نمونه، پس از آزمون صدا در artifacts/tomorrow-radio-preview.wav تولید می‌شود.

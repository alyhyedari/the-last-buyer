# BUY BUTTON · The Last Buyer

بازی وب داستانی پیکسلی با **انگلیسی پیش‌فرض** و هشت زبان: انگلیسی، فارسی، چینی ساده، عربی، اسپانیایی، هندی، فرانسوی و پرتغالی. نسخهٔ **0.10.0 / WILD SIGNAL** رانندگی، محلهٔ نئون، جمعیت متنوع، جنگل بزرگ‌تر، مهمان‌های ناشناس و دنیای زیر آب را به شهرستان اول‌شخص اضافه می‌کند. روستا، هشت فصل آرشیو و رادیوی تعاملی حفظ شده‌اند. زبان انتخاب‌شده در ورودهای بعدی حفظ می‌شود. [راهنمای کامل نسخهٔ تازه](WILD-SIGNAL.fa.md).

## سفر به شهرستان پس‌تاب

در روستا دکمهٔ **Beyond the village / آن‌سوی روستا** را بزنید. راهنما ابتدا شما را به فروشگاه وسیله می‌برد؛ دوچرخه با پول شروع بازی قابل خرید است. دوباره همان دکمه را بزنید تا به دروازه بروید و **Take the road / بزن به جاده** را انتخاب کنید. تصویر سوم‌شخص به نمای اول‌شخص تبدیل می‌شود. نقشهٔ شهرستان مقصدها را نشان می‌دهد و گزینهٔ مسیر، شخصیت را واقعاً تا مقصد حرکت می‌دهد.

- جهان ۱۹۲×۱۹۲ با ۳۵ مقصد متصل و ۵۱ ساختمان قابل ورود؛ اتاق خواب، آشپزخانه، نشیمن و حمام با دیوار و مبلمان برخوردپذیر. محلهٔ نئون، جنگل جنوبی با ۴۰ مخفیگاه، روز و شب، باران، صاعقه و گردباد. چیدمان طبیعت، کارها و هوا با بذر مخصوص هر ذخیره متفاوت‌اند.
- چهار مدل ماشین با فرمان تدریجی، چسبندگی متفاوت، دور موتور، برف‌پاک‌کن، بوق، چراغ، سلامت بدنه و محل پارک ماندگار. برداشتن ماشین دیگران سلامت و مدل همان وسیله را منتقل می‌کند و پیامد دارد. ترافیک برای مانع جلوی خود می‌ایستد؛ ورود ناگهانی به مسیر خطر برخورد دارد.
- دو دریاچه با شنا و غواصی، نفس‌گیری، ماهی، لاک‌پشت، عروس دریایی، گیاه و صندوق زیر آب. راهنمای ساحل و برگشت به نقطهٔ ورود؛ مرگ در آب کوله را روی ساحل قابل بازیابی می‌گذارد.
- ۱۵۰ شهروند با ۱۲ ظاهر و برنامهٔ روز/عصر/شب؛ فرار از شلیک. مهمان‌های دوستانه اعتماد را به خاطر می‌سپارند و موجودات خصمانه رفتار نبرد دارند. راکت به خودرو، درخت و اشیای شهری آسیب می‌زند؛ لاشه و کنده بعد از ذخیره باقی می‌مانند.
- دوچرخه، موتور، ماشین و اسب با شتاب، ترمز، عرض عبور، ظرفیت بار و رفتار متفاوت روی خاک و باران. نگاه‌کردن از فرمان‌دادن جداست؛ دستهٔ دوچرخه، داشبورد و گوش‌های اسب نماهای متفاوت دارند. خریدهای قبلی حفظ می‌شوند.
- ساختمان، تنهٔ درخت، تابلو و وسایل شهری برخورد دارند؛ ترافیک حرکت می‌کند و تصادف روی سلامتی اثر می‌گذارد. شش گونهٔ حیات‌وحش، پرندگان عبوری، سگ و گربه و امکان سرپرستی یکی از آن‌ها وجود دارد.
- تپانچه، شاتگان، مسلسل، لانچر و نارنجک در کنار کمان و تفنگ؛ کمک عمودی نشانه، مانع واقعی گلوله، سلامت هدف، افکت محدود خون با سه تنظیم و آسیب وابسته به سرعت تصادف. دزد، زامبی، جن، خون‌آشام و نگهبان رفتارهای متفاوت دارند. مرگ، پول و تجهیزات همراه را در کولهٔ قابل بازیابی روی نقشه باقی می‌گذارد.
- چادر، استراحت کنار آتش، دعوت نورا پس از شکل‌گیری رابطه و صعود به قله. دزدی، آسیب‌رساندن و مصرف مادهٔ خیالی پیامد قابل‌مشاهده دارند و راه جبران و درمان هم وجود دارد.
- تحویل بار با دستمزد، تعمیر مدار، ماهیگیری با انتخاب فروش یا رهاکردن، اجرای نت‌های موسیقی و تمرین روی اهداف کاغذی متحرک.
- کاباره با زمان اجرا، نوشیدنی، همراهی خصوصی بزرگسالان با روایت غیرصریح و رابطه‌ای که با گفت‌وگو در روزهای جدا رشد می‌کند. استراحت رایگان جلوی گیرکردن بازیکن بی‌پول را می‌گیرد.
- معمای سه رسید و **۱۲ پایان داستانی تازه**، علاوه بر ۲۴ پایان آرشیو و ۲۸ سرنوشت روستا. این سه مجموعه مسیرهای جدا دارند؛ دفتر سفر پایان‌های کشف‌شدهٔ شهرستان را نگه می‌دارد. پایان، روایت انتخاب‌های همان دور است و تشخیص شخصیت یا روان‌شناسی محسوب نمی‌شود.
- انیمیشن ۹۴۰ میلی‌ثانیه‌ای دست پیکسلی که کلاهک سبز دکمهٔ فیزیکی BUY را فشار می‌دهد؛ بدون مسدودکردن کنترل. در حالت کاهش حرکت، تأیید ثابت ۵۰۰ میلی‌ثانیه‌ای نمایش داده می‌شود.
- صدای محیط جنگل، آب، شهر و کوهستان، حرکت وسیله و آوای جانوران با فاصله و جهت؛ صداها با Web Audio ساخته می‌شوند و حجم دانلود فایل صوتی اضافه ندارند.

کنترل شهرستان: `W/S` حرکت، `A/D` چرخش، `Q/E` حرکت جانبی در پیاده‌روی، `I/K` نگاه بالا و پایین، `R` تراز دید، `B` ترمز، `T` نشانه‌گیری، `X` یا `Space` شلیک، `Z` تعویض سلاح، `F` تعامل، `V` سوار/پیاده، `M` نقشه، `H` آموزش و `Esc` توقف. کشیدن ماوس، نگاه در دو محور است؛ راست‌کلیک نشانه‌گیری و کلیک کوتاه با سلاح شلیک می‌کند. روی لمس، نیمهٔ چپ کنترل متحرک و نیمهٔ راست نگاه است؛ دکمه‌های واضح نشانه و شلیک هم وجود دارند. در حالت کلیک برای حرکت، ابتدا نشانه را روشن کنید یا دکمهٔ شلیک را بزنید. ذخیرهٔ خودکار، بازگشت به همان نقطه و حفظ موقعیت روستا فعال است.

کنترل‌های تازه: `C` بوق، `L` چراغ و `Space` غواصی/سطح هنگام شنا. دکمه‌های روی صفحه همین کارها را انجام می‌دهند. منوی اصلی پیش‌نمایش شهر، جنگل و زیر آب دارد.

جهان بازی محدود است؛ خانه‌ها نقشهٔ داخلی دارند و چیدمان پایهٔ اتاق‌ها مشترک است. ساختمان‌ها فرو نمی‌ریزند و فعالیت‌های خدماتی با پنل یا صحنهٔ تعاملی اجرا می‌شوند. دامنه و جزئیات این بازی مستقل با RDR2 هم‌مقیاس نیست. راهنمای تغییرات و محدودیت‌ها: [سیگنال وحشی](WILD-SIGNAL.fa.md). داستان و پایان‌های شهرستان: [نسخهٔ پس‌تاب](AFTERLIGHT.fa.md).

## اجرا و ساخت

Node.js 24 و npm لازم‌اند:

```powershell
npm ci
npm run dev
```

نشانی توسعه: `http://localhost:4173`. فایل HTML را مستقیم با file:// باز نکنید. سرور محلی روی 127.0.0.1 گوش می‌دهد؛ برای انتخاب پورت از متغیر PORT استفاده کنید.

```powershell
npm run check
npm test
npm run build
npm run preview
```

پیش‌نمایش و توسعه به‌صورت پیش‌فرض از یک پورت استفاده می‌کنند؛ پیش از جابه‌جایی، سرور قبلی را متوقف کنید. موتور بازی مستقل از سرویس خارجی اجرا می‌شود. esbuild و playwright-core ابزار توسعه‌اند؛ بستهٔ رسمی Speed Insights برای سنجه‌های کارایی در ساخت Production روی Vercel اضافه شده است.

## انتشار از GitHub به Vercel

راهنمای قدم‌به‌قدم اولین push و اتصال مخزن: [انتشار روی GitHub و Vercel](DEPLOY.fa.md).

فایل `vercel.json` در ریشهٔ پروژه قرار دارد:

| تنظیم | مقدار |
|---|---|
| Framework Preset | Other |
| Node.js | 24.x |
| Install | npm ci --include=dev |
| Build | npm run build |
| Output Directory | dist |
| متغیر محیطی و پایگاه داده | لازم نیست |

پوشهٔ همین پروژه را در مخزن GitHub قرار دهید و مخزن را از Vercel Import کنید. ریشهٔ پروژه باید همان پوشهٔ package.json باشد. تنظیم‌های نصب، build و output در vercel.json ثبت شده‌اند. ابزار ساخت نیز در نصب صریحاً لحاظ می‌شود. در این جلسه هیچ مخزن، commit، push یا استقرار ابری ساخته نشده است.

build کد را bundle و minify می‌کند و نام JavaScript، CSS، فونت و آیکون را با اثرانگشت محتوا می‌سازد. دارایی‌های نسخه‌دار کش بلندمدت دارند و HTML دوباره اعتبارسنجی می‌شود. نه فایل خروجی محلی و ده فایل در ساخت Production روی Vercel قرار می‌گیرند؛ فایل اضافه، راه‌انداز Speed Insights است. سورس، آزمون، تنظیم توسعه و نمونهٔ صوتی منتشر نمی‌شوند. خطای مسیر واقعاً 404 است. سیاست CSP با کد و سبک‌های بازی سازگار شده است.

گزارش حجم در `artifacts/build-report.json` تولید می‌شود. build با عبور از بودجهٔ ۴۳۶ KiB برای جمع gzip یا ۲۳۸ KiB برای JavaScript اولیه، شامل تمام فایل‌های اشتراکی، شکست می‌خورد. بودجه برای سامانه‌های WILD SIGNAL افزایش یافته؛ بخش شهرستان جداگانه در دروازه بارگیری می‌شود. خروجی فعلی حدود ۴۲۲٫۶ KiB gzip و JavaScript آغاز حدود ۲۳۴٫۳ KiB است. این اعداد برآورد فشرده‌سازی فایل‌ها هستند، نه زمان دانلود یا کارایی گوشی.

گردش‌کار `.github/workflows/ci.yml` روی push به main/master و pull request، نصب قفل‌شده، بررسی نحو، تست واحد و build را اجرا می‌کند. استقرار از اتصال مخزن به حساب Vercel انجام می‌شود.

**Speed Insights:** اتصال مخصوص JavaScript معمولی با `@vercel/speed-insights@2.0.0` آماده است. تنها ساخت `VERCEL_ENV=production` روی سایت HTTPS سنجه می‌فرستد؛ Preview و localhost از آمار حذف‌اند. query و fragment آدرس قبل از ارسال پاک می‌شوند. ذخیرهٔ بازی و گزارش تست دستگاه در این اتصال ارسال نمی‌شوند. راه‌انداز حدود ۱ KiB gzip اضافه می‌کند؛ حجم اسکریپت Vercel در زمان اجرا جداست. برای ثبت آمار، قابلیت باید در داشبورد پروژه فعال باشد و همین تغییرات روی Production منتشر شوند. جزئیات در بخش Speed Insights از [راهنمای انتشار](DEPLOY.fa.md) آمده است.

مستندات پیکربندی: https://vercel.com/docs/project-configuration/vercel-json
و نسخهٔ Node: https://vercel.com/docs/functions/runtimes/node-js/node-js-versions

## تست دستگاه و کیفیت

پیش از نخستین سفر، آزمایش قابل‌مشاهدهٔ Canvas ارائه می‌شود: حدود ۲٫۲ ثانیه اجرای صحنهٔ پیکسلی با ۳۵۰ میلی‌ثانیه آماده‌سازی. میانه و صدک ۹۵ فاصلهٔ فریم‌ها، زمان ترسیم، تعداد نمونه‌ها و سهم فریم‌های کند نمایش داده می‌شوند. امتیاز از همین اندازه‌گیری‌ها به‌دست می‌آید؛ تعداد پردازندهٔ منطقی یا حافظه امتیاز را تغییر نمی‌دهد.

نتیجهٔ الگوریتم نسخهٔ ۲ با تاریخ، اندازهٔ پنجره و اطلاعات کلی گزارش‌شدهٔ مرورگر در `last-buyer.benchmark.v1` ذخیره می‌شود. این گزارش آزمون قطعی قدرت سخت‌افزار یا سنجش مستقل GPU نیست؛ ساعت نمایشگر و فشار فعلی مرورگر روی آن اثر دارند. اطلاعاتی که مرورگر ارائه نکند، خالی نمایش داده می‌شود. داده به سرور ارسال نمی‌شود.

نتیجهٔ معتبر در ورود بعدی دوباره مطالبه نمی‌شود. منوی Device check و تنظیمات امکان تکرار و دریافت JSON دارند. لغو، بسته‌شدن پنجره یا پنهان‌شدن صفحه آزمایش را قطع می‌کند. شکست ذخیره‌سازی به‌صراحت اعلام می‌شود؛ نتیجه برای همان جلسه کاربرد دارد. ادامه بدون آزمایش نیز ممکن است و امتیاز ساختگی تولید نمی‌کند.

نتیجه نقطهٔ شروع کیفیت خودکار است و انتخاب دستی بازیکن را عوض نمی‌کند. حالت خودکار در طول بازی فشار مداوم را می‌سنجد، پس از دو بازهٔ ضعیف سبک می‌شود و فقط پس از چهار بازهٔ پایدار کیفیت را بالا می‌برد. هدف نمایش ۶۰ یا ۳۰ فریم است؛ موتور سوم‌شخص گام ثابت ۶۰ هرتز دارد و شهرستان حرکت را از زمان سپری‌شده محاسبه می‌کند. تصاویر ثابت کش می‌شوند و صفحهٔ پنهان متوقف می‌شود.

## گوشی و جهت نمایش

در دسکتاپ، صحنه هنگام ورود کل پنجره را می‌گیرد و درخواست تمام‌صفحه از همان کلیک ورود انجام می‌شود. دکمهٔ تمام‌صفحه در تنظیمات شهرستان هم در دسترس است. اگر مرورگر درخواست را رد کند، نمای پرکنندهٔ پنجره باقی می‌ماند.

صفحهٔ لمسی کوچک با اندازهٔ پنجره و نوع اشاره‌گر تشخیص داده می‌شود؛ User-Agent لازم نیست. هنگام ورود به بازی، درخواست تمام‌صفحه و قفل landscape از همان تعامل بازیکن انجام می‌شود. در مرورگرِ پشتیبان، صحنه افقی می‌شود.

اگر مرورگر درخواست را نپذیرد، کارت راهنمای چرخاندن گوشی نشان داده می‌شود؛ صحنه و زمان بازی تا آماده‌شدن بازیکن متوقف‌اند. چرخش فیزیکی، چیدمان افقی را فعال می‌کند. گزینهٔ ادامهٔ عمودی برای دسترسی‌پذیری وجود دارد. با بازگشت به منو، قفل و تمام‌صفحه‌ای که خود بازی ایجاد کرده آزاد می‌شوند.

نمای افقی نوار ابزار کوتاه، دکمه‌های حداقل ۴۴ پیکسلی، حاشیهٔ امن بریدگی صفحه و بوم با نسبت درست دارد. مختصات لمس با قاب تصویر محاسبه می‌شوند؛ کل صفحه با CSS چرخانده نمی‌شود. تست مرورگر شامل ۸۴۴×۳۹۰ و ۵۶۸×۳۲۰، فارسی و انگلیسی، چرخش به عمودی و مسیر‌یابی واقعی با لمس است. این تست شبیه‌سازی است؛ گوشی فیزیکی و Safari هنوز بررسی نشده‌اند.

## بازی و کنترل

- میدان آزاد ۱۹۲۰×۱۲۸۰؛ هفت مسیر آزاد و بازار آخر که با کامل‌شدن مغازه، اتاق تسویه و دو فصل دلخواه باز می‌شود.
- هشت فصل، ۲۴ ایستگاه و ۴۸ مرحلهٔ معما، هشت صحنهٔ اختصاصی، ۳۲ سند و حداکثر ۱۵ تصمیم صریح.
- ۲۴ پایان در شش خانواده، هرکدام با سه قاب روایی؛ اطلس، سرنخ شرط‌های هر مسیر، حفظ سابقهٔ پایان‌ها و بازگشت به انتخاب آخر.
- شش کشف و سه پروژهٔ اختیاری: چراغ‌ها، نامه‌ها و ملودی گربه.
- سایه با دید محدود به دیوار، شنیدن دویدن، جست‌وجو و پناه. تعلیق تدریجی، پوشش پیکسلی، شدت قابل‌انتخاب و حالت آرام.
- راهنمای معما و حل کمکی؛ کمک، سرعت، ترس، زبان و دستگاه در گزارش بازتاب تصمیم‌ها امتیاز شخصیتی نمی‌سازند.
- WASD/جهت برای حرکت، Shift دویدن، E تعامل، Space نور رسید، C خم‌شدن، J دفترچه، M نقشه و Escape توقف. حرکت به مقصد با کلیک و لمس نیز وجود دارد.

گزارش پایان، انتخاب‌های همین سفر و شواهدشان را توضیح می‌دهد؛ تشخیص روان‌شناختی یا برچسب قطعی شخصیت نیست.

## موسیقی

نه قطعهٔ اصلی با چرخهٔ ۶۴ میزان، ملودی و تنظیم متفاوت، از سازهای Web Audio ساخته می‌شوند. رادیو شامل انتخاب قطعه، میکسر پنج لایه، کنترل جداگانهٔ موسیقی و محیط، سرعت ۶۰ تا ۱۳۲ BPM و چهار ردیف شانزده‌مرحله‌ای برای ساخت ریتم است. ریتم شخصی در تنظیمات ذخیره می‌شود و بازی تازه پاکش نمی‌کند.

حالت موسیقی همراه سفر، قطعه را با مکان هماهنگ می‌کند. موسیقی در صفحهٔ پنهان متوقف می‌شود. فایل صوتی تجاری یا دانلود حجیم صدا وجود ندارد. نمونهٔ شنیدنیِ ابزار آزمون فقط در `artifacts/tomorrow-radio-preview.wav` تولید می‌شود و در dist نیست. سنجش عددی صدا انجام شده؛ شنیدن انسانی و مسترینگ هنوز لازم است.

## ذخیره و تاریخچه

ذخیرهٔ بازی نسخهٔ ۴ است. نسخه‌های ۱ تا ۳ هنگام خواندن مهاجرت می‌کنند؛ سابقه‌ای که ثبت نشده جعل نمی‌شود. کلیدهای دیگر: `last-buyer.save.v1` و `last-buyer.settings.v1`. ذخیرهٔ خودکار، خروجی JSON و واردکردن فایل معتبر در دسترس‌اند. مراحل کامل‌شده حفظ می‌شوند؛ حرکات مرحلهٔ ناتمام پس از بستن همان مرحله از ابتدا آغاز می‌شوند.

اطلس پایان‌ها در سفر تازه حفظ می‌شود؛ هر پایان سابقهٔ تصمیم‌های همان سفر را دارد. بازگشت به انتخاب آخر، تصمیم‌های قبلی را تغییر نمی‌دهد. بعضی مسیرهای متناقض فقط در سفر تازه باز می‌شوند. پاک‌کردن دادهٔ سایت ذخیره‌ها را پاک می‌کند؛ پیش از آن خروجی بگیرید. هیچ کیف پول، خرید یا سفارش واقعی در بازی وجود ندارد.

## آزمون‌ها

برای آزمون مرورگر، Microsoft Edge نصب‌شده و `npm ci` لازم‌اند. ابتدا `npm run dev` را در ترمینال دیگر اجرا کنید:

```powershell
npm run test:browser
npm run test:mobile
npm run build
npm run test:release
```

آزمون انتشار سرور موقت خودش را از dist با هدرهای ثبت‌شدهٔ Vercel اجرا و در پایان می‌بندد. ابزارها از مرورگر جداگانه و دادهٔ ساختگی استفاده می‌کنند. مسیر داستان شخصیت را کنار اشیا قرار می‌دهد، سپس همهٔ معماها، صحنه‌ها و تصمیم‌ها از رابط واقعی اجرا می‌شوند. این روش زمان تجربهٔ انسان را اندازه نمی‌گیرد. نتایج و تصاویر در artifacts و گزارش خواندنی در [QA.md](QA.md) هستند.
